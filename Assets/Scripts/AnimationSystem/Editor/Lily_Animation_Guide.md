# 릴리(Lily) 애니메이션 제작 가이드

본 문서는 아트팀/애니메이터가 릴리(주인공 플레이어)의 스프라이트 애니메이션을 제작하고 유니티 에디터에 세팅할 때 참고해야 할 **상태(State) 목록표 및 네이밍 규칙**입니다.

---

## 📌 스프라이트 에셋 네이밍 규칙

애니메이션 에셋 파일 이름은 다음 규칙을 지켜서 저장해야 엔진에서 자동으로 인식하고 연결합니다.
> **규칙:** `캐릭터이름_상태이름_파트이름`

- **예시 (몸통)**: `Lily_Idle_Body`, `Lily_Dash_Body`
- **예시 (이펙트/무기)**: `Lily_Attack_Sword`, `Lily_Dash_Effect`

---

## 🏃‍♀️ 릴리(Player) 필수 애니메이션 State 표

현재 스크립트에 구현되어 있는 릴리의 행동 패턴(State) 목록입니다. 가운데 **`상태 이름 (State Name)`** 열에 적힌 영단어가 파일명에 들어가야 할 정확한 키워드입니다.

| 행동 분류 | 상태 이름 (State Name) | 설명 및 연출 가이드 | 루프(반복) 여부 |
| :--- | :--- | :--- | :---: |
| **기본 이동** | `Idle` | 가만히 서 있는 대기 모션 (호흡 등 둥실둥실) | O |
| | `Move` | 지상 좌우 이동 (걷기/가벼운 달리기) | O |
| | `Dash` | 짧고 빠른 순간 대쉬 | X |
| **공중/점프** | `Jump` | 점프 상승 구간 (위로 올라갈 때) | O |
| | `Fall` | 점프 하강 구간 (아래로 떨어질 때) | O |
| | `Glide` | 공중 활공 (망토 등을 펴고 천천히 떨어짐) | O |
| **전력 질주 (Sprint)**| `Sprint` | 고속 전력 질주 상태 | O |
| | `SprintJumpPrepare`| 전력 질주 중 점프를 뛰기 직전 압축/준비 프레임 | X |
| | `SprintTurn` | 전력 질주 중 급격히 반대 방향으로 돌 때 (미끄러짐) | X |
| | `SprintStop` | 전력 질주를 멈추고 브레이크를 걸 때 | X |
| | `SprintImpact` | 전력 질주 중 벽에 쾅 부딪혔을 때 | X |
| **벽/지형 상호작용** | `WallSlide` | 벽에 매달려 천천히 미끄러져 내려올 때 | O |
| | `WallClimb` | 벽을 타고 위로 올라갈 때 | O |
| | `WallJump` | 벽을 차고 반대편으로 도약할 때 | X |
| | `LedgeClimb` | 모서리(턱)에 매달렸다가 위로 올라올 때 | X |
| **특수 이동** | `GrappleAim` | 훅샷(그래플링)을 던지기 위해 조준하는 자세 | O |
| | `Grappling` | 훅샷 줄에 끌려가며 날아가는 자세 | O |
| **전투/상태이상** | `Hit` | 적에게 피격 당했을 때의 충격 모션 | X |
| | `Parry` | 적의 공격을 쳐내기(패리) 성공했을 때 | X |
| | `Death` | 체력이 0이 되어 사망할 때 쓰러짐 | X |
| **기타** | `Transform` | 다른 폼(Form)으로 변신하는 모션 | X |

### 💡 애니메이터 참고 사항 (Tip)
1. **Jump / Fall 구분**: 시스템 코드에서 공중에 있을 때 상승 중이면 `Jump`, 하강 중이면 `Fall`로 애니메이션을 자동으로 갈아 끼웁니다.
2. **파트 분리 (Part ID)**: 만약 공격 모션 중 검 궤적이나 잔상을 분리하고 싶다면, 캐릭터 본체는 `Lily_Attack_Body`로, 검 이펙트는 `Lily_Attack_Sword`로 만들어서 한 애니메이션 세트 안에 두 개 다 넣으시면 시스템이 동시에 재생합니다.
3. **Looping 설정**: 위 표에서 **루프(반복) 여부가 'O'인 것**들(Idle, Move, Jump, Glide 등)은 에디터에서 `SpriteAnimationData`를 만드실 때 **`Is Looping`** 체크박스를 반드시 켜주셔야 합니다.
